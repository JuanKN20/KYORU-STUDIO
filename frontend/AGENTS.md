# Frontend Working Rules

- Read `DESIGN.md` before visual or interaction work.
- Kyoru's approved identity, product truth, and project constraints take precedence over external skills or generic patterns.
- Use Impeccable for visual critique when it materially helps the task. Use Emil-related skills only for motion or interaction work that explicitly requires them.
- Do not load or execute skills indiscriminately.
- Preserve accessibility, responsive behavior, semantic structure, and functionality outside the authorized scope.
- Do not invent clients, projects, metrics, media, claims, or capabilities.
- Run `npm run validate` before handing off relevant frontend code changes.
